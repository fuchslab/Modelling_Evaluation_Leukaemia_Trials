# Dynamic modelling and evaluation of preclinical trials in acute leukaemia
This repository provides the R code for the statistical analyses reported in the paper "Dynamic modelling and evaluation of preclinical trials in acute leukaemia", including both the simulation study and the knockout experiments. Simulated data, experimental data, and inference results are included as RDS files. Shared utility functions are implemented in utils.R. This repository is archived on Zenodo [![DOI](https://zenodo.org/badge/1143398810.svg)](https://doi.org/10.5281/zenodo.21259066).
